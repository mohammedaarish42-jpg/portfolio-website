# Personal Portfolio Website

A responsive portfolio showcasing skills, projects and contact information.

**Technologies:** HTML, CSS, JavaScript

## Files
- `index.html` – the content: about, skills, projects, contact (HTML)
- `style.css` – the look and the mobile layout (CSS)
- `script.js` – mobile menu, typing animation, scroll effects, contact form (JavaScript)

## How to open it
Double-click `index.html`. It opens in your browser; nothing to install.

## How to personalise it
- **Your name:** open `script.js` in Notepad and change `"Your Name"` on line 2.
- **About text, skills and projects:** open `index.html` in Notepad and edit the text.
- **Skill levels:** in `index.html`, change the `data-level="90"` numbers (0–100).
